# Kylerjensen Tap

## How do I install these formulae?

`brew install kylerjensen/tap/<formula>`

Or `brew tap kylerjensen/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kylerjensen/tap"
brew "<formula>"
cask "<cask>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
